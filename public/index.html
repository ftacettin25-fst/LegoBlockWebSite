FAQ

Common questions

How long does it take?

Most builds are ready within a few minutes. Shipping varies by region.

Which photo works best?

A bright, front-facing portrait with clear features works best. Avoid sunglasses and heavy filters.

Do you ship internationally?

Yes, we ship worldwide. Shipping options appear at checkout.

Can I get just the .ldr file?

Yes — every order includes the .ldr file and PDF guide so you can build it yourself.
